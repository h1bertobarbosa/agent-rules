---

## Etapas
1. **Preparar branch**
   - Certifique-se de que todas as alterações foram commitadas
   - Envie o branch para o remoto
   - Verifique se o branch está atualizado com a main
2. **Escrever descrição do PR**
   - Resuma as alterações de forma clara
   - Inclua contexto e motivação
   - Liste quaisquer breaking changes
   - Adicione screenshots se houver alterações na UI
3. **Configurar PR**
   - Crie o PR com título descritivo
   - Adicione labels apropriadas
   - Atribua revisores
   - Vincule issues relacionadas
## Template do PR
- [ ] Feature A
- [ ] Correção de bug B
- [ ] Testes unitários passaram
- [ ] Testes manuais concluídos
