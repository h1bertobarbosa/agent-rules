# Node.js/TypeScript

All source code should be written in TypeScript.
Use npm as the standard tool for managing dependencies and running scripts.
If necessary, install types from libraries, for example: jest and @types/jest.
Before finishing a task, always check that the typing is correct.
Use const instead of let where possible.
Never use var to declare a variable.
Always declare class properties as private or readonly, avoiding public.
Prefer the use of find, filter, map, and reduce instead of for and while.
Always use async/await to handle promises, avoid using callbacks.
Never use any, always use existing types, or create types for everything you implement.
Never use require to import modules, always use import.
Never use module.exports to export modules, always export.
If the file only has one thing being exported, use default, otherwise named exports
Avoid circular dependencies
